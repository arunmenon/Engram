Fetched and retained the Palantir Foundry "Submission criteria" page (https://www.palantir.com/docs/foundry/action-types/submission-criteria/) on 2026-09-29; the page carries no version or revision id. The note records, verbatim where quoted:

- Definition: "Submission criteria (formerly known as validations) are the conditions that determine whether an action can be submitted." All criteria must pass; they do not replace base permissions.
- Supported condition types: Current User (user id, direct or inherited groups, multipass attributes such as Organization), Parameter (the action's own parameters; attachment and object-set parameters unsupported), Execution Context (inside an Ontology Scenario or not).
- Operators: is, is not, matches, is less than, is greater than or equals; includes, includes any, is included in, each is, each is not. Nestable all / any / none combinators.
- Per-condition failure messages: "Every condition and logical operator on the root level has its own failure message."
