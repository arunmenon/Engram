## Item 2: setup (found, `html`, "Experiment Setup" fold, verbatim)

- "We compare 21 model-harness pairs on the same 30 randomly sampled tasks from each benchmark: SWE-bench Lite and Terminal-Bench 2.0. We run each pair three times per task ... select its high effort setting, and cap each attempt at 100 agent turns ... We measure task success using each benchmark's official evaluator."
- "We average cost and success across each task's three attempts, then across the 30 tasks. We estimate 95% confidence intervals using 10,000 bootstrap resamples ... We compute token costs using a fixed direct-API price list dated September 1, 2026, applying the same prices to each model across harnesses."
- SWE-bench Lite: external network blocked, default web tools disabled in Claude Code and Codex, hosted tool declarations rejected.
- Pi: "we add two packages to configure subscription keys and control agent turns." Kimi K3 via Fireworks AI.
- Harness versions (`system-agent-context-swe.json` `context.rows[].version`): Pi 0.85.1, Codex 0.146.0, Claude Code 2.1.224; n=630 first calls each.
