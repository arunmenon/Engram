claim: On build-time questions over our seeded project history, when the served memory contains one superseded Decision rewritten to contradict the current one among hard negatives (the misleading condition), an admission gate run by Jev Noul `quote_supports_item` before the executor cuts the executor's wrong-answer rate by at least 20 points against the executor's own abstain instruction, while falsely abstaining on at most 15% of questions it answers correctly with gold memory (one-sided 95% upper bound below 20%).

Sources and what they do and do not show. N-SURVEY-20261003-04: with one entity-swapped passage among five, an explicit abstain prompt still answered 13.6% to 74.3% of the time across small quantised models and 59.6% of answers echoed the planted entity (abstract says 63%; table value used); NLI (P3) and closed-book (P4) checks cut the answer rate to 13.3% and 14.0% but falsely abstained on 49.8% and 31.0% of answerable questions, and AURC did not improve (0.434, 0.451, 0.452); swap audit found 13% of swaps broken. Limits: small quantised models only, no trained gate, no typed decision model, QC-eligible questions are easier, code not released. The card's numbers match the note. No register experiment or open spec tests admission under a misleading memory: H5 measures extraction precision, E-20260926-05-r2 tests a none option and a recall gate on unanswerable prompts (irrelevant, not contradicting, memory), E-20261003-01-r2 tests poison authority, not stale decisions; their arms cannot answer which component owns admission when memory is wrong, so this is not merged.

conditions (same 120 questions, each built in four context variants of five memories): G gold (gold Decision plus four related negatives; answerable); I all-irrelevant; R degraded (gold plus hard negatives, three related distractors); M misleading (the current Decision replaced by a superseded Decision rewritten to contradict it, plus hard negatives; correct behaviour is abstain or answer from the current Decision if present elsewhere, which it is not by construction). Variants authored by one person blind to arm outputs, from the seeded history's real Decision supersessions where they exist (target at least 60 of 120) and constructed otherwise; each M item audited for a well-formed contradiction (broken items replaced before freeze).

arms (same pinned executor model and abstain instruction in every arm; the gate removes items before the executor sees them; if all items are removed the executor receives an empty context and must abstain):
- P (baseline): executor's explicit "abstain if the memory does not support an answer" instruction, no gate.
- L (NLI gate, reported decision arm): DeBERTa-v3-large MNLI (pinned hash), item removed if contradiction probability against the question's claim set exceeds a threshold, or entailment probability is below a threshold, both fitted on the fit split.
- N (decision arm): Jev Noul `quote_supports_item` (pinned version) per item, item admitted if P(yes) at least t_N fitted on the fit split; neutral option names.
- O (open-weight reported arm): the first of Bongard, decider-2b, KEV-9B whose licence permits self-hosted internal use, same question as N, threshold fitted the same way; not run (and recorded) if no licence permits.
- threshold fitting objective (all gates): minimise wrong-answer rate on M plus false abstention on G, equal weights, on the fit split; ties to the higher threshold.

metric: primary, wrong-answer rate on M = share of M questions where the executor gives a substantive answer that is wrong (includes echoing the superseded value), graded against the frozen key by a frozen string-and-entity grader with a human audit of 60 graded items; false abstention on G = share of G questions answered correctly by P that the arm abstains on; answer rate and echo rate per condition; AURC over the four conditions; gate p95 latency; calls and tokens per question.

predeclared margin: positive for N needs wrong(P, M) minus wrong(N, M) at least 0.20 with the one-sided 95% cluster-bootstrap lower bound above 0.10, and false abstention(N, G) at most 0.15 with one-sided 95% upper bound below 0.20. Negative for N: wrong(P, M) minus wrong(N, M) below 0.10, or false abstention(N, G) one-sided 95% lower bound above 0.20. L and O are judged by the same rule and reported; if both N and L pass, N is preferred only if its false abstention on G is lower by at least 0.05 (else the cheaper, L, is preferred).

sample size and power note: 60 fit and 60 test questions per condition (split by seeded project component, frozen seed 20261109), clustered by underlying Decision (about 40 test clusters). With the note's echo pattern, wrong(P, M) is expected near 0.5 and a working gate near 0.15; paired discordance about 0.4 gives SE about 0.065, so the 0.10 lower bound clears with probability about 0.9 at a 0.35 true gain and about 0.5 at a true 0.20 gain. The false-abstention bound needs the true rate near 0.08 to clear 0.20 with about 0.8 probability at n=60; joint pass power at the expected effect about 0.7. This is a pilot; `tl power` runs before any model call.

kill criterion: negative for N as above. Invalid: context items edited after any arm ran; contradiction audit pass rate below 0.9 on M; grader human-audit agreement below 0.9; thresholds fitted on test questions; pins differ; per-arm failure rate above 3%; fewer than 54 scored test questions per condition in all arms.

what a pass unlocks: which component owns admission in /v1/context (Noul gate vs prompted abstention vs NLI), before H5's scorer earns production shadow; B11 (working: admission is separate and must allow empty) gains a local measurement on the case that matters for build-time agents, a stale Decision; a stale-decision family for the PDLC memory benchmark (priority 4).

cost (runs, tokens, people-days): fixture build 3 engineer-days (variants, contradiction audit, key); gate arms 2 engineer-days; grader and audit 1 day. Model tokens: executor 4 arms x 480 test-and-fit contexts x about 3k = 5.8M is over plan, so the executor runs on test only for all arms and on fit only for the gate arms' threshold sweep via cached gate scores: executor 4 arms x 240 test contexts x 3k = 2.9M plus fit executor runs for P only (240 x 3k = 0.7M, used to define the threshold objective's abstention set); Jev 480 contexts x 5 items x about 0.4k = 1.0M; O self-hosted about 1.0M; NLI local, negligible tokens; total about 5.6M in 5 shards, cap 7M.
