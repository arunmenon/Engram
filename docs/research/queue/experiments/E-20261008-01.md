claim: With retrieved evidence, item set and token budget held fixed, the reader-facing rendering of memory changes memory QA accuracy on our stack by more than the re-judge noise floor: our current typed briefing versus a natural-language rendering of the same items differ by at least 5 accuracy points for at least one of two readers from different model families. Source: arXiv 2608.23568 (N-SURVEY-20261007-02, paper-ablated): with evidence fixed, deployed-style templates spread 24.6 to 48.8 points per reader, MemGPT-style typed records scored 14.8 to 33.0%, and three of nine readers scored 0% on formal ledger packets while answering the same facts from natural-language entries. Those are oracle-evidence results on other templates; whether our typed briefing sits in the harmful region is untested, which is the question. The decision it serves is harness design: if the renderer moves scores this much, H2, H3 and H8 comparisons must run on a frozen renderer or they compare templates, not memories.

arms:
- A (baseline): current Engram typed briefing renderer at the pinned harness commit, applied to the oracle evidence items for each question.
- B: natural-language renderer: each item rendered as one plain sentence (subject, statement, date) in the same order, no field labels, no ledger syntax; same items, same order, same truncation budget (tokenizer-level, using the reader's tokenizer count from A as the cap).
- Two readers, one per family, pinned by version string, temperature 0: one Anthropic and one non-Anthropic model. Identical question prompt; only the memory block differs.

metric: answer accuracy per item by a frozen judge (judge model from a third family not used as a reader; prompt frozen), and refusal or "not enough information" rate. Statistic: paired difference B minus A per reader, 95% paired bootstrap CI (10,000 resamples, seed 7), clustering unit = question (LongMemEval) and source project (PDLC items).

predeclared margin: renderer effect counts if |B minus A| >= 5 points with the 95% CI excluding 0 for at least one reader. 5 points is well above the re-judge noise floor (about 3 answers in 500, N-SURVEY-20261007-01) and far below the source's smallest template spread (24.6).

sample size and power note: 250 paired items per reader. For a paired binary outcome with about 20% discordant pairs, the 95% CI half-width on the difference is about 5.5 points; a true 10-point effect is detected with power above 0.8, a 5-point effect is not reliably detected. This is a screen for a large effect, matching the decision (freeze or not), not a fine estimate. PDLC items, if present, are reported separately and do not enter the primary.

kill criterion: renderer effect absent: for both readers the 95% CI of B minus A lies within [-5, +5] points. Then freeze A in P3 without a renderer arm.

what a pass unlocks: renderer frozen and versioned as part of P3's frozen evaluate(); served packets stored with every score (needed for P4 receipts and for the PDLC benchmark); a later spec on which format ships.

cost (runs, tokens, people-days): 1 run; 2 arms x 2 readers x 250 items = 1,000 reader calls at about 1,300 tokens each (oracle evidence is short) plus 1,000 judge calls at about 300 tokens, about 1.6M tokens, estimated under 8 USD at pinned prices; 1 people-day for the natural-language renderer, 0.5 for analysis.
