claim: Inside our system, with everything else fixed, write-time supersession (superseded items kept but excluded from recall) together with contradicts-edge inhibition at read time raises knowledge-update accuracy on our PDLC histories by at least 5 points over the same system with every new unit simply added, with other question classes non-inferior within 5 points. Conclusions apply to this local intervention only; they do not identify what caused REALM's whole-system gap over Zep.

arms:
- Edge construction (shared by every arm): each new unit is processed once, in ingestion order, against a common immutable candidate history: the up-to-10 candidates are retrieved from the edges-off store (all prior units, nothing suppressed), so candidate sets never depend on an arm's earlier suppression. One pinned decision call per unit returns contradiction score c in [0, 1], relation in {supersedes, contradicts, none} and target id among the candidates (or null). Calls, candidates and outputs are logged once; every arm is materialised by applying its rule to the same log.
- Rules applied to the log:
  - supersede edge (two-signal): c >= 0.7 AND relation = supersedes AND target id not null.
  - supersede edge (single-signal, B2 only): c >= 0.7, target = top-ranked candidate, relation ignored.
  - contradicts edge: c >= 0.7 AND relation = contradicts AND target id not null.
- 2 x 2 factorial plus a rule variant:
  - A (neither): every unit added; edges not used at read time.
  - S (supersession only): superseded items tagged (P5 `superseded` state) and excluded from recall; contradicts edges ignored.
  - I (inhibition only): contradicts edges dropped from expansion at read time (REALM's conflict_inhibit); superseded items not excluded.
  - B (both): S and I together; the primary bundle.
  - B2: as B but with the single-signal supersede rule.
- Everything else fixed: extractor, embedder, fusion, k, token budget, answerer and judge. No oracle-session warm-up (REALM A.4's path is excluded): every store is built only from the history before the question's cut-off time. Answerer and judge are pinned models from different families from each other and from the decision model; the judge sees only (question, answer, reference), with arm labels stripped.

metric: primary: knowledge-update accuracy (blinded judge) on PDLC knowledge-update questions. Non-inferiority: accuracy on PDLC other-class questions asked against the same stores. Rule quality on the sealed contradiction test set: false-supersede rate on near-misses and missed-supersede rate on reversals, each with a Clopper-Pearson interval. Secondary: factorial main effects of S and I; LongMemEval_S knowledge-update accuracy (78 questions) if the optional stage runs; served tokens.

predeclared margin: bundle_helps requires (ku_B - ku_A) >= 0.05 with the 95% cluster-bootstrap interval excluding 0, AND ci95_low(other_B - other_A) >= -0.05, AND on the sealed test set ub95(false-supersede rate of B) <= 0.05 (at least 90 near-misses; 1 or fewer false supersedes is needed). Component attribution (reported, not a gate): the S and I main effects with intervals; a component is called "carrying" only if its main-effect interval excludes 0. Rule choice on the sealed test set: two_signal_needed if fs_B2 - fs_B >= 3 with one-sided exact McNemar p < 0.05; two_signal_costly if missed_B - missed_B2 >= 3 with one-sided exact McNemar p < 0.05; otherwise rule_choice_inconclusive, with the two-signal rule kept as the operational default (not a finding of equivalence).

sample size and power note: primary: at least 280 PDLC knowledge-update questions from at least 8 repositories (at least 20 per repository); with about 15% discordance the SE of the paired difference is about 0.023, so the detectable difference at 80% power is about 6.5 points; a true 5-point effect will often be inconclusive, and the spec says so rather than lowering the margin. Non-inferiority: at least 320 PDLC other-class questions against the same stores; with about 10% discordance the SE is about 0.018, so a true difference of 0 passes the -0.05 bound with about 80% power (a -0.02 bound, as in r1, would need about 2,000 questions and is unaffordable; the margin is widened and stated, not hidden). Other-class questions are cheap because they reuse the PDLC stores; only answerer and judge tokens are added. Sealed contradiction test set: at least 60 reversals and at least 90 near-misses (0 or 1 false supersede in 90 bounds the rate below about 5.2%); dev part at least 20 reversals and 30 near-misses. Clusters: repository (and haystack for LongMemEval).

kill criterion: bundle_bounded: ub95(ku_B - ku_A) < 0.05.
