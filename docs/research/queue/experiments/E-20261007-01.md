claim: On PDLC artifacts (requirements, design sections, tickets, pull requests, tests) with our small schema (7 node types; trace links implements, verifies, refines, satisfies, blocks), extracting without the schema in the prompt, canonicalising types by embedding similarity and repairing only constraint violations (arm B) yields trace-link F1 against an adjudicated gold no more than 3 points below schema-in-prompt extraction (arm A) while using at least 20% fewer tokens per artifact. Secondary: a System One decision model confined to the ambiguity band and yes/no repair (arm C) is no more than 3 F1 points below arm B. Source: N-SURVEY-20261006-02 (OAK+MEND: 96.8% vs 79.4% schema-valid triples at 0.59x vs 0.79x token cost, equal HotpotQA F1, n=1000; Wikidata-style ontology; validity is schema consistency, not correctness) and N-SURVEY-20261006-03 (small generative models fail at free typed-link emission: Mistral 7B triple F1 4.2; strict gold undercounts correct links, 61.5% of one model's triples absent from gold, many supported). The note's own open question is whether the gap survives a small schema where in-prompt constraints are cheap; this test answers exactly that, so the card's paper-single-benchmark strength supports a question, not an expected effect size.

arms:
- A (baseline): extractor model M, full node and link schema with domain/range rules in the extraction prompt, one pass, no repair.
- B: same model M, open extraction with no schema in prompt; types and link predicates canonicalised by cosine similarity (Qwen3-Embedding-0.6B) to schema labels; when several candidates lie within 0.05 of the best, M chooses; symbolic domain/range check; M repairs only violating links.
- C: as B, but ambiguous canonicalisations and violation repairs are decided by a System One decision model as yes/no per candidate link type (hosted Jev; Decision-2.0-Nox-4B reported as a secondary, not decided on).
- M is pinned (same model, temperature 0, same seed) across arms. Rendering of artifacts and chunking are identical.

metric: primary, trace-link F1 (exact source node, target node, link type) against the adjudicated gold. Secondary: link precision, recall, schema-valid rate, input plus output tokens per artifact, p95 latency per artifact. Statistic: paired difference arm B minus arm A in F1, with a 95% cluster bootstrap CI (10,000 resamples), clustering unit = repository.

predeclared margin: non-inferiority margin 3 F1 points (B vs A, and C vs B); token saving at least 20% (B vs A, mean per artifact).

sample size and power note: 300 artifacts from at least 8 public repositories, about 600 gold links expected. With per-artifact F1 SD near 0.25 and paired correlation near 0.6, the CI half-width on the paired difference is about 2 points before clustering; with 8 clusters it may widen to about 3, so this is sized as a decisive test only if the observed gap is under 1 point, otherwise inconclusive. State that in the verdict rather than reading a narrow miss as a pass.

kill criterion: stop and report negative if, after the first 100 artifacts (3 repositories), arm B's F1 is more than 8 points below arm A, or arm B's token cost per artifact is not below arm A's.

what a pass unlocks: removing the schema from every PDLC extraction prompt; a fixed slot for the System One model (ambiguity band and repair) in the priority 3 narrow slice; refines H5 (where the typed gate sits) and H7 (cleaner typed links feeding supersession).

cost (runs, tokens, people-days): 3 arms x 300 artifacts, about 1.5M tokens, under $8 per run; 1 run. People-days: 2 for gold adjudication (two annotators, a third resolves), 1 for harness.
