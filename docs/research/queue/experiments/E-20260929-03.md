claim: On our own labelled linking decisions (supersedes, contradicts and the PDLC trace links implements, verifies, refines, among others labelled in LINK-ASF-LOCOMO v2), an open-weight decision model run zero-shot on one workstation GPU, Winnow-12B Q8, is non-inferior to hosted Jev 1.13 within 3 accuracy points after each model's thresholds and temperature are refit locally; the same comparison on write-gate save/skip decisions is run as a pilot. Cygnet and Jeff-Qwen3.5-2B are reported, not decided on. Source: N-20260929-09 (JevBench v1.5.0, third-party, vendor-benchmark grade): on 1,624 generic decisions run in evaluator-owned offline containers, Cygnet 73.7 and Winnow-12B Q8 73.2 lead hosted Jev 1.13 at 72.1 on the composite; Winnow-12B is above Jev outside the 95% interval (difference CI [0.28, 2.08]); Intelligence 74.4 (Winnow) and 71.1 (Cygnet) against 72.0 (Jev), Calibration 84.1 and 87.0 against 88.0. Limits that make our test necessary: generic decisions, no memory-stage task; the composite mixes accuracy with the evaluator's latency and cost; the Calibration metric is undefined in what the note read; hosted APIs saw sealed text; Cygnet versus Jev not separately reported. Winnow-12B is the primary arm because it is the only open model with a resolved gap above Jev on that board; naming one primary arm avoids a multiplicity correction.

arms (identical state and question text for every model, rendered through one request contract; each model's thresholds and temperature refit on the same fit data):
- J (baseline): hosted Jev 1.13, pinned.
- W (primary): Winnow-12B Q8_0 GGUF (pinned file sha256), served by llama.cpp on one GPU.
- Y (reported): Cygnet (frozen Gemma-4-12B-it with its published shim, pinned revisions), same GPU.
- F (reported): Jeff-Qwen3.5-2B (pinned revision), local Jev-shaped API.
- override: JEV-27B is dropped; it needs an 80 GB-class GPU for one reported arm, and the priority 2 question is what runs on one workstation GPU. The card's implements-link family is not duplicated here: E-20260928-08-r2 already compares hosted Jev with a self-hosted open model on SpecMine implements pairs; this spec uses the trace-link pairs labelled in LINK-ASF-LOCOMO v2 instead.

metric: accuracy per family (primary): write gate, save/skip correct against labels on WG-TURNS v1 (300 turns) with thresholds chosen per model by E-20260929-02's procedure (AI Maestro rule form, 2-fold session-grouped cross-fitting); linking, per pair and link type, link or no-link correct against adjudicated labels on the 800 test pairs of LINK-ASF-LOCOMO v2 (600 PDLC, 200 LoCoMo), with per-type thresholds fit per model on that dataset's dev slices. Secondary: ECE with 10 equal-mass bins after a temperature refit on the fit data; states over 1,024 tokens reported separately (two arms truncate); p50 and p95 latency on our GPU; USD per 1,000 decisions (billed for J; GPU-hour rate times measured wall time at the measured throughput for local arms); licence.

predeclared margin: per family, W is non-inferior if the one-sided 95% lower bound of (W minus J) accuracy is above minus 3 points (the card's margin, JevControl-style paired bootstrap). An arm is dropped for a family if its point estimate is more than 5 points below J with the two-sided 95% interval wholly below zero, or its ECE after refit exceeds 0.08.

sample size and power note: linking: 800 test pairs, discordance between two competent models about 0.12, design effect about 1.3 for pairs sharing a write: SE = sqrt(0.12 / 800) x sqrt(1.3), about 1.4 points; at a true difference of 0, non-inferiority at minus 3 is shown with probability Phi(3 / 1.4 minus 1.645), about 0.69; at a true 3-point loss, a false pass has probability 0.05. Write gate: 300 turns, SE about 2.3 points; at a true difference of 0, about 0.37: this family is a pilot that can reject a large gap and sizes a confirmatory run. ECE: with 800 predictions and 10 bins, the noise floor for a well-calibrated model is about 0.02 to 0.03, well under the 0.08 drop line.

kill criterion: W is dropped for linking if (W minus J) is below minus 5 points with the interval wholly below zero, or its ECE after refit exceeds 0.08; if W is dropped for linking, linking stays hosted this quarter. A point estimate below minus 5 whose interval reaches zero is inconclusive. Invalid (rerun under a new spec revision, not a verdict): any model seeing a different rendered state than J for the same item (checked by per-item state sha256); thresholds or temperature fit on test items; WG-TURNS v1 or LINK-ASF-LOCOMO v2 labels not frozen by their own specs; a model file sha256 or licence record missing.
