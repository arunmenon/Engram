claim: On our own link and staleness decisions, adding retrieved neighbouring memories to Jev's state as free text changes decisions well beyond Jev's re-run floor, and placing the same neighbours in a separate field labelled by `source_class`, with opinion sentences marked unverified, reduces that excess. Source: arXiv 2609.31142 (N-SURVEY-20260928-09), one appended unverified opinion flipped 12.1% of 812 typed decisions on jev-1.13.0 (+11.1 pp over a 1.0% re-run floor) and pushed 38.0% of confident (>= 0.8) answers below 0.8. None of the source tasks are memory decisions and no paper tests a defence; 82.4% of that benchmark's labels are model-derived. The typed-field mitigation is an inference from "fields outside the schema never reach the model", not a measured result.

arms (same question, options and rubric in every arm; option names neutral per E-20260928-06's recommendation, A/B, since this spec must not depend on its outcome):
- A (targets only): the state contains only the target memories of the decision (for "does B supersede A?": A and B; for "is A still true?": A plus the current snapshot excerpt H10 defines).
- A' (re-run): A repeated with identical bytes, for the floor.
- B (neighbours as free text): A plus the top-5 neighbours the serving path would retrieve for the target, concatenated as free text in the state, as `/v1/context` would serve them.
- C (neighbours typed): the same neighbours as B, in a separate field `neighbours`, each with `source_class` (user-stated, tool-result, inferred, imported) and with sentences expressing an opinion or evaluation marked `unverified: true` by a deterministic rule (first-person or attributed evaluative verbs list, fixed before the run and published in the bundle).
- Probe set: on the 100 gold-labelled items, one neighbour is replaced with a planted unverified opinion that contradicts the gold answer (for example "I think A was reverted last week" when it was not), in arms B and C. Planted text is written before the run and frozen.

metric:
- Primary (label-free, JevAdvBench scoring): flip rate of B vs A and of C vs A, where a flip is a changed decision on the same item; floor = flip rate of A' vs A. Excess = arm flip rate minus floor.
- Threshold crossing: share of A decisions with confidence >= 0.8 that fall below 0.8 in B and in C (floor: same measure for A').
- Labelled: F1 against gold on the 100 labelled items per arm, and on the probe set the rate at which the decision moves to the planted opinion's answer.
- Recorded per decision: top-two probability gap (small-gap decisions reported separately).

predeclared margin: Passing neighbours as free text is a risk if B's excess flip rate on the non-probe set exceeds 5 pp. The typed field helps if C's flip rate is lower than B's by at least 5 pp with the paired 95% cluster interval of (B minus C) excluding zero, on the non-probe set or on the probe set.

sample size and power note: 200 non-probe decisions plus 100 probe variants, each in 3 or 4 arms, is about 1,100 Jev calls. With a floor near 1% and a source effect near 11 pp, 200 paired items give roughly 80% power to detect a 5 pp B-vs-C difference only if discordant pairs number at least about 25 (inference from a McNemar approximation); if the non-probe excess in B is below 5 pp, the B-vs-C comparison is underpowered by design and only the probe set is decisive. Decisions are clustered by decision thread (all decisions touching the same target memory or the same design topic); intervals are cluster-bootstrapped by thread and the number of threads is reported.

kill criterion: For passing neighbours at all: if B's excess flip rate over A on the non-probe set is 5 pp or more, the serving-path construction is not used for automatic writes. For C as the mitigation: if C's flip rate is not lower than B's by more than the re-run floor on both the non-probe and the probe sets, the typed field is killed as a defence and the fallback is arm A construction (no neighbours) for automatic decisions.

what a pass unlocks: The state-construction rule for every System One decision that reads stored memories (linking, supersession, staleness), fixed before H10a and E-20260928-08 ship; a measured answer to whether a 0.8 confidence gate is safe for automatic writes (B14); the first defence measurement in the cluster the source papers left open.

cost (runs, tokens, people-days): about 1,100 Jev calls (a few US dollars at the source paper's rate, estimate); 3 people-days to extract 200 decisions from project history and H10's seeded history, label 100, and write the probe opinions; 1 people-day for the harness. Cost S.

Frozen as JSONL plus a manifest with per-item sha256 and the neighbour retrieval configuration; manifest sha256 recorded before the first call.

Paired difference B minus C with a 95% cluster bootstrap (10,000 resamples, clustering unit: decision thread). Crossing rate = share of items with conf_A(i) >= 0.8 and conf_X(i) < 0.8. F1 on the 100 labelled items per arm.
