claim: On our stack, deleting only the target node leaves the erased fact reachable through Summary nodes, merged nodes and cached context bundles derived from it (probe leak rate at least 0.30), while deleting the target plus its derived-from closure and regenerating summaries from surviving sources brings the leak rate to at most 0.05 with non-target utility within 5 points. Source: arXiv 2609.04875 (N-SURVEY-20261009-02), memory delete Any-Leak 0.94, identical to no forget.

arms:
- A (baseline, current behaviour): delete the target node only.
- B: delete the target and every node reachable over derived-from edges (P5 provenance), regenerate each affected Summary node from its surviving sources, invalidate cached context bundles that served any deleted node.
- Reference R (not compared for the claim): rebuild the tenant from raw events with the targets removed; used for the cost ceiling only.

metric: primary: leak rate = fraction of probes (6 per target: 3 direct, 3 indirect, plus one downstream agent task) whose served /v1/context payload contains the erased fact (string and id match) or whose agent action reflects it (deterministic check). Secondary: non-target accuracy on 30 control questions, regeneration tokens and wall time vs R.

predeclared margin: B passes if leak(B) <= 0.05 and leak(A) - leak(B) >= 0.25 with target-clustered 95% bootstrap lower bound above 0.10, and non-target accuracy drop <= 5 points.

sample size and power note: 30 targets x 7 probes = 210 probes, cluster = target. The paper's gap is 0.94 vs 0.00, so 30 clusters detect a gap of 0.25 easily; the run is not powered to estimate small residual leaks below 0.05 (zero leaks in 210 correlated probes bounds the per-target rate at about 3/30 = 10%, rule of three, B21).

kill criterion: leak(A) < 0.10 (the failure does not reproduce on our stack); or B's regeneration tokens exceed R's rebuild tokens.

what a pass unlocks: erase semantics distinct from suppress (R2 thesis), a compliance answer we can state with a number, and a new register belief on erasure completeness; requires P5 provenance fields to be populated on derived nodes.

cost (runs, tokens, people-days): one run, Consumer 4 summarisation plus probes, about 1.2M tokens, estimated $5 to $8; 4 people-days (taint closure walker and probe set).
