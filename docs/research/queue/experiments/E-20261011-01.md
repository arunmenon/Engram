claim: On a frozen memory question set, a decision-model relevance cutoff (keep candidates with score >= 0.8, floor 1) over the same candidate pool keeps gold-evidence recall within 1 point of fixed top-6 while lowering total cost per correct answer (answer model plus reranker) by at least 10% at some pool size in {10, 25}; the source (DocsBot, N-20261010-01) reports +67.1% total cost at its pool size, so we expect the cutoff to lose at 25 and may win at 10.

arms:
- A (baseline): hybrid retrieval (BM25 + dense, RRF k=60), fixed top-6 from the pool, no reranker.
- B10, B25: hosted Jev relevance question per candidate over the top-10 or top-25 of the same hybrid pool; keep score >= 0.8; if none clears, keep the single highest.
- C10, C25: open-weight decision model (Laya, pinned checkpoint, zero-shot; fine-tune is out of scope for this run) with the same rule.
Fetch depth is identical across arms: every arm draws from the same frozen top-25 pool per question; A and the 10-pool arms use its prefix. Same answer model, same prompt, temperature 0.

metric: primary: total cost per correct answer (USD; answer-model tokens at list price plus reranker calls at list price, or for C the measured GPU-seconds at a stated rate). Co-primary guard: gold-evidence recall (fraction of questions where at least one served item comes from an answer evidence session). Secondary: served tokens, latency p50/p95, answer correctness.

predeclared margin: B or C at a given pool size passes if (i) recall difference (arm minus A) has a question-clustered 95% bootstrap lower bound above -1 point, and (ii) cost per correct answer is at least 10% below A with the bootstrap upper bound of the ratio below 1.0.

sample size and power note: 300 questions, one cluster per question. With baseline recall near 0.85 and paired discordance about 10%, the standard error of the paired recall difference is about 1.8 points, so a -1 point non-inferiority bound needs the true difference to be about +2.5 or better; this run is powered for the cost claim (expected effect 30 to 60%), not for small recall deltas. State it as a cost test with a recall guard. Correctness judged by a model that is not the answer model, against the LongMemEval reference answer.

kill criterion: if cost per correct answer for every B and C arm is at or above A's, drop the cutoff for the default path. Also stop if A's correctness is above 0.95 (no headroom).

what a pass unlocks: a decision-model cutoff in the default read path at the passing pool size; a cost-per-correct-answer rule for every later R3 assembly comparison; moves B9 from lead toward working for a per-item cutoff and tests B11's "ranker never returns empty" floor in practice.

cost (runs, tokens, people-days): 5 arms x 300 questions, one run; about 1.6M answer-model tokens plus 300 x 70 reranker calls; estimated $12 to $20 model cost; 3 people-days to build the arm wrapper and cost ledger.
