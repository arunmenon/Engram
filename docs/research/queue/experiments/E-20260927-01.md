claim: On our frozen engineering-agent traces, a decision-model pass/fail judge (one binary rubric proposition per trace, threshold fixed on a dev split) is non-inferior to our LLM judge on agreement with blinded human labels (95% lower bound of the difference >= -0.05), has failure recall no lower than the LLM judge's, and flips verdicts on no more traces across repeated calls, at lower cost per decision.

arms:
- Arm A (incumbent): the P3 LLM judge, structured output {verdict, confidence, rationale}, pinned model and prompt.
- Arm B: decision-model judge, one yes/no proposition per trace; pass if P(yes) >= tau, where tau maximises balanced accuracy against human labels on the dev split and is frozen in `threshold.json` before any test trace is judged.
- Shared: the same rubric proposition for both arms ("Did the agent complete the task stated in `task` so that its stated acceptance checks would pass?"); the same deterministic trace rendering capped at 16,000 tokens (task statement, final diff, test and CI output, then the most recent turns until the cap), so both arms see a byte-identical payload; traces that hit the cap are flagged and analysed as a subgroup. Neither judge model is the agent model that produced the traces, and neither is used as answerer in any run it judges.
- Human labels: every trace labelled pass/fail by one labeller blind to both judges and to the executable oracle result; a second blind labeller on 100 test traces for inter-rater agreement; disagreements adjudicated by a third person. Labellers are not the rubric or threshold author.

metric: primary: agreement with human labels on the test split; failure recall = share of human-labelled test failures judged fail. Repeatability: 60 fixed test traces x 10 calls per arm, count traces whose verdict flips at least once. Secondary: expected calibration error of B's P(yes) and A's confidence on the test split (10 equal-width bins; this is what can move B14); agreement with the executable oracle where one exists (supporting evidence, not ground truth); cost per decision and p50/p95 latency; the capped-trace subgroup.

predeclared margin: judge_pass requires ci95_low(agree_B - agree_A) >= -0.05 AND (recall_B - recall_A) >= 0 AND ci95_low(recall_B - recall_A) >= -0.10 AND flips_B <= flips_A AND cost_per_decision_B < cost_per_decision_A.

sample size and power note: B21 governs the sizes. Agreement: 300 test traces with about 10% paired discordance give an SE of about 0.018, so with a true difference of 0 the lower bound clears -0.05 with about 78% power; at 15% discordance power falls to about 50%, and the spec says so rather than widening the margin. Failure recall: at least 75 human-labelled failures in test (at least 25 in dev); the SE of the paired recall difference is about 0.05, so the recall rule is a guard (point >= 0 and lower bound >= -0.10), not a superiority claim; the card's source had 29 failures, which this more than doubles. Repeatability: 0 flipped traces of 60 bounds the flip rate at about 4.9% (one-sided 95%). Clustering unit: task family; at least 20 families, none split across dev and test.

kill criterion: keep_llm_judge if (recall_B - recall_A) < -0.05 OR ci95_high(agree_B - agree_A) < -0.05 (the decision model is clearly worse on the endpoint that matters for gating). Stop before running (not a result) if fewer than 400 traces or 100 human-labelled failures exist, the egress review for sending traces to the hosted decision model has not cleared, the threshold was written after any test trace was judged, or any pin is missing.
