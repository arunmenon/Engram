claim: On a frozen set of build-time engineering tasks whose artifact pool contains superseded, conflicting and falsely-final documents, serving the same top-k artifacts each with an authority label and a one-paragraph evidence report raises the task rubric pass rate by at least 5 points over serving the same top-k unlabelled, without misclassifying more than 5% of authoritative artifacts as superseded or false final.

arms (same frozen executor, same retrieval, same top-k artifact ids and order, same token ceiling; only the served decoration differs):
- Arm A (baseline): current retrieval, top-k artifacts served as-is.
- Arm B (deterministic labels): each artifact labelled from ledger supersession edges only (authoritative if no outgoing superseded-by edge, superseded otherwise), with a templated one-line evidence report naming the superseding artifact id and date. No model call.
- Arm C (model labels, the card's arm): one typed choice per artifact over the six Env-Rethink authority classes (authoritative record, false final version, fabricated authority, misleading redirection, superseded version, out of scope), conditioned on the artifact, its supersession edges and its top-k neighbours, plus a one-paragraph evidence report, both prepended to the artifact.
- Arm D (hide, secondary): the Arm B labels are used to drop superseded artifacts from the served set instead of labelling them; the freed budget is not refilled.
- Held equal: task prompt, executor pin, retrieval config and pool, top-k ids, served-token ceiling (labels count against it; if a label pushes a block over the ceiling the lowest-ranked artifact is truncated in every labelled arm the same way).

metric: primary: rubric pass rate per task (share of predeclared rubric items passed, averaged over 3 rollouts), Arm C minus Arm A. Secondary: B minus A; C minus B; D minus the better of B and C; label error rates against ledger ground truth (authoritative mislabelled as superseded or false final; superseded mislabelled as authoritative); served tokens per task; labeller tokens and latency. The judge scores rubric items blind to arm and does not share a model family with the executor or the labeller.

predeclared margin: primary: labels_help if (C minus A) >= 0.05 and ci95_low(C minus A) > 0. Secondary comparisons use Holm correction across B minus A, C minus B and D minus best-label. Ship-B rule: if labels_help and ci95_low(B minus C) >= -0.03, the deterministic arm ships instead of the model arm (deterministic first). Label safety bound: authoritative-mislabel rate for C at most 0.05 of authoritative artifacts, else labels_help cannot ship C regardless of pass rate.

sample size and power note: 60 tasks, 3 rollouts each; the unit is the task (rollouts are averaged and estimate model variance only). Clustering unit: source repository (at least 8 repositories, no repository contributing more than 10 tasks). Assuming a per-task SD of the paired difference of 0.15 and a design effect of 1.3 from repository clustering, the SE of C minus A is about 0.022, so a true 5-point gain is detected with about 60% power and a true 8-point gain with about 95% power. Env-Rethink's whole preparation pass gained 13.3 points on average (range 3.4 to 17.8), but that bundles Collection Maps, Event Logs and version resolution; labelling alone was not ablated, so a smaller effect is expected and a 5-point true gain may read inconclusive. The spec says so rather than claiming equivalence.

kill criterion: the claim is killed if (C minus A) < 0.05 or ci95_low(C minus A) <= 0, or if C's authoritative-mislabel rate exceeds 0.05. Stop before running (not a result) if fewer than 60 tasks or 8 repositories exist, any task pool lacks a seeded superseded and conflicting artifact with ledger edges, the judge shares a model family with the executor or labeller, any pin is missing, or the rubric was edited after the first scored run.

what a pass unlocks: the design of the Spec-time curate step (labelled supersession at read, not only at write); whether ledger supersession edges alone are enough (Arm B) or a model labeller earns its call; an answer to Env-Rethink's open question of labelling versus removing superseded material (Arm D); a local measurement extending B7 (lead) to long structured artifacts, which JITMem did not cover, and bearing on B8's typed-structure clause.
