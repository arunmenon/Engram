claim: On TWIST Track B (161 human-validated items: 38 contradicting, 61 aligned, 62 hard-negative drafts), with the same retrieved top-k memories for every arm, one Jev noul per retrieved memory ("does this draft contradict memory item X?", with explicit true and false criteria that name the acknowledged-pause and change-question cases as not contradictions), flagging when the highest probability is at least a threshold fitted on other conversations, reaches hard-negative specificity at least 0.10 higher than the flat-RAG GPT-4o flagger while keeping contradiction recall within 0.10 of it and grounded contradiction recall within 0.05. Source: N-20260930-03 (TWIST, arXiv 2609.28575, per-item outputs and frozen key public; paper-single-benchmark): flat RAG with GPT-4o reached CR 0.97 [.87, 1.0] but HNS 0.57 [.44, .68]; flat RAG with Claude 0.92 / 0.74 and Gemini 0.76 / 0.84; even gold evidence with GPT-4o flagged too much (HNS 0.42), so the judgement step, not retrieval, drives false flags for that backend; the author's deployed coherence system had HNS 0.98 but CR 0.42. Scoring is structural (verdict and evidence turn ids against a key), no LLM judge. Limits that make our test necessary: one track of four instantiated; 161 items, with 38 contradicting items making recall intervals wide; raw inter-annotator kappa 0.565 before adjudication dropped 39 items; single author who founded the deployed system tested; GPT-4o generated the items and is one of the backends; LoCoMo chat memory, not engineering records. No System One model has been measured on it (the note's open question). N-SURVEY-20260929-04 adds that Jev had the highest contradiction recall of ten models on ContractNLI (77.27%) at one sixth to one four-hundredth of the others' cost, with its weakest class being "not mentioned", which is the shape of a hard negative here.

arms (identical items, identical retrieved top-k from our retriever for A, B and C; flag = the item is declared a contradiction; evidence = the arm's top-3 memory turn ids):
- A (control): the TWIST flat-RAG flagger prompt at the pinned commit, GPT-4o (pinned snapshot, temperature 0), over our retriever's top-k; verdict and evidence ids parsed as TWIST's harness does.
- A2 (reported): the same prompt with our default LLM checker (model id pinned in `freeze.json`), to show whether the result is specific to GPT-4o.
- B (decision arm): hosted Jev (pinned version), one noul per (draft, retrieved memory) pair, question text and true/false criteria fixed in `prompts/contradicts.json` before any run; flag if max P(true) >= t; evidence = the top-3 memories by P(true); t fitted per fold (below).
- C (reported): the same noul on laya-typed-decisions served locally through Unsloth's Jev-compatible API (same server commit and model revision as E-20260929-03-r2's L arm, pinned here independently), thresholded on `probabilities`, never `confidence`; items over its window counted as 422, not re-rendered.
- O-A, O-B (reported): A and B given the gold evidence turns instead of the retrieved top-k, to separate retrieval failure from judgement failure as TWIST's oracle rows do.
- override: the card fits t on 40 items and tests on 121. This spec uses 2-fold cross-fitting grouped by conversation (5 conversations per fold, assignment frozen with seed 20261019 and balanced on class counts), so every item is tested once with a threshold fitted on the other five conversations; this uses all 161 items as test and keeps fitting and testing on disjoint conversations. The card's fixed split is reported beside it for comparison.

metric: on held-out predictions pooled over both folds: contradiction recall (CR) on contradicting items; aligned specificity (AS); hard-negative specificity (HNS); grounded contradiction recall (GCR, a correct flag with at least one gold evidence turn in the arm's top-3); attribution accuracy (reported); cost and p50 latency per item; Jev repeat disagreement: every Jev call is sent twice with canonical option order, and the share of items whose flag differs between the two calls is reported (the card cites 4.3% repeat flips from another note). Threshold rule for B and C, predeclared: on the fit fold, t is the grid value (0.05 to 0.95 by 0.05) maximising Youden's J = CR + specificity on aligned and hard-negative items pooled minus 1; ties go to the higher t.

predeclared margin: positive needs HNS(B) minus HNS(A) at least 0.10 with the two-sided 95% interval excluding zero, CR(A) minus CR(B) at most 0.10 (point estimate), and GCR(B) at least GCR(A) minus 0.05 (point estimate).

sample size and power note: 62 hard negatives and 38 contradicting items, all used as test once. HNS: paired discordance between a strict and a permissive flagger is likely 0.25 to 0.35; SE of the paired HNS difference about sqrt(0.3 / 62), 0.07; the interval rule needs a mean above about 0.14, so at a true gain of 0.20 P(positive) is about 0.8, at a true 0.10 about 0.3. CR: with 38 items and discordance about 0.1, SE about 0.05. This is pilot-scale on a public set: it can show a large specificity gain (the size of the gap between flat-RAG GPT-4o and the better backends, 0.17 to 0.27) and cannot resolve a small one. Clustering: items share 10 conversations; an item-level paired bootstrap stratified by class is primary, and a conversation-cluster bootstrap is reported beside it (10 clusters are too few to be the primary unit; this is stated, not hidden).

kill criterion: negative if the upper 95% bound of HNS(B) minus HNS(A) is below 0.10, or if CR(A) minus CR(B) exceeds 0.10 with its interval excluding zero. Invalid (rerun under a new spec revision, not a verdict): the TWIST key or item file differing from the pinned commit's sha256; the retrieved top-k differing between A, B and C for any item; a threshold fitted using a test-fold conversation; the Jev version or the noul text differing from the pin; any of the 161 items missing from an arm's output.

what a pass unlocks: which implementation sits at the linking stage for contradicts links and at the pre-action check (priority 1: a System One model at the linking stage, where the field has no evidence); a measured answer for B11 (working) on whether an admission-type flag that is allowed to stay silent can keep recall, and for B13 (lead) on whether the larger model is better on the borderline population (the hard negatives); the design for PDLC contradiction items with surface-matched hard-negative twins for the PDLC memory benchmark (priority 4), before we build them.

cost (runs, tokens, people-days): no labelling (public frozen key); harness 2 engineer-days (TWIST's harness reused for parsing and structural scoring; our retriever over LoCoMo turns). Model tokens: embedding the 10 LoCoMo conversations, about 0.25M; Jev: 161 items x (5 retrieved plus about 3 gold) pairs x about 600 tokens x 2 calls = 1.55M; GPT-4o: 161 x 2 (retrieved and gold) x about 2k = 0.65M; our default LLM, the same, 0.65M; Laya local: 161 x 5 x about 600 = 0.5M; total about 3.6M in 3 shards, aggregate hard cap 4.5M.
