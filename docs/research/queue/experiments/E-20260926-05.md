claim: On our held-out set, a listwise choice ranker with no "none" option that always serves at least one memory, placed behind a separate recall/no-recall gate, keeps gold retention within 0.02 of the ungated ranker on answerable queries and reaches at least 20 points higher correct abstention on unanswerable and opt-out prompts, whereas giving the ranker a "none" option loses at least 0.05 gold retention on answerable queries.

arms:
- Arm A (shipped Hindsight design): one listwise choice call over the candidate pool, no "none" option, top 5 served, at least 1 always served.
- Arm B (shipped jevmem design): the same choice call with an added option "No listed memory is relevant to the query."; serve the top 5 memory options with probability >= 0.05; serve nothing if none clears it.
- Arm C: a yes/no gate before retrieval ("Does answering this prompt need project memory? False if the prompt asks not to use memory."); on no, serve nothing; on yes, serve Arm A's result for that query (reused, not recomputed, so the only difference is the gate).
- Shared: candidate pool = top 60 from H2's fusion (RRF k=60), candidate text truncated to 120 tokens, same seeded candidate order in every arm, same decision model and version for the ranker and the gate, same frozen answerer and judge. Order control: on a 100-query subset, Arms A and B are re-run with two more seeded candidate orders and order sensitivity is reported. PC-20260926-03 is not an open spec, so this spec carries its own order control.

metric: primary: gold retention on answerable queries (fraction of gold evidence items in the served set; 0 when nothing is served); correct abstention on unanswerable queries (frozen answerer declines, as scored by the frozen judge) and opt-out compliance (nothing served on an explicit opt-out prompt). Secondary: empty-result rate on answerable queries, end answer accuracy on answerable queries, gate latency p95, decision-model tokens.

predeclared margin: split_confirmed: A minus B gold retention >= 0.05 with the 95% cluster-bootstrap interval excluding 0. gate_earns_call: C minus A correct abstention (unanswerable and opt-out pooled) >= 0.20 with the 95% interval lower bound >= 0.10, AND A minus C gold retention <= 0.02 (point) with the one-sided 95% upper bound <= 0.04.

sample size and power note: target at least 300 answerable, 100 unanswerable and 50 opt-out prompts, clustered by source conversation or project (at least 30 clusters). B differs from A only where the none option wins; Hindsight saw that on 35 of 200 LoCoMo questions, so a 0.05 retention loss is well inside what 300 answerable queries resolve (SE of the paired difference about 0.015 if the empty rate is near 6%). For abstention, with 150 unanswerable plus opt-out prompts and a paired discordance near 30%, the SE of the difference is about 0.045, so a 20-point gain is detectable at about 80% power while a 10-point gain is not; hence the lower-bound rule of 10 points. Clustering widens all intervals; the verdict reports the effective number of clusters.

kill criterion: none_harmless: the 95% upper bound of A minus B gold retention is below 0.02 (the Hindsight failure does not reproduce on our pools; the split in B11 is unnecessary for recall). gate_not_worth_call: the 95% upper bound of C minus A correct abstention is below 0.10. Stop before running (not a result) if the P3 held-out split lacks the unanswerable or opt-out classes, or any pin is missing.
