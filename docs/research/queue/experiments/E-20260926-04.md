claim: At a matched token budget, task-conditioned curation at Spec time (H3) does not exceed anchored hybrid retrieval (top BM25 items first, then RRF fill) by 3 or more points of spec-task success.

arms:
- Arm A (strong-retrieval control): anchored hybrid: top lexical (BM25) hits placed first, then RRF (k=60) over vector, BM25 and entity channels fills to the budget. Deterministic.
- Arm B: H3 task-conditioned curation (the curator chosen for H3) selecting from the same candidate pool, at the same token budget.
- Arm C: Arm A's candidates reordered by the curator's scores and truncated to the same budget (curation as a rerank feature).
- All arms share the frozen executor, frozen judge, candidate pool and budget. This is an added arm set for H3, not a replacement of H3's write-time arms; run on the same harness so H3's comparison and this one share the executor and judge.

metric: spec-task success as scored by the frozen H3 judge; secondary: evidence recall on tasks with gold evidence, served tokens, curator latency and cost.

predeclared margin: Arm B ships as the selector only if B >= A + 3 points with the paired, repository-clustered 95% interval excluding zero. Arm C is kept as a rerank feature only if C >= A + 1 point.

sample size and power note: the source paper's +1.79 points was not significant at n = 503. For paired binary outcomes with a 15 to 20% discordance rate, detecting 3 points at 80% power needs roughly 1,300 to 1,750 tasks; the H3 task set is expected to be a few hundred. At n = 200 only differences of about 8 to 9 points are detectable. The spec therefore places the burden of proof on curation: an underpowered result defaults to the cheaper deterministic arm (A), and the verdict must say "not detectable at this n" rather than "no effect". The test split is scored once, after all prompt and budget choices are fixed on the dev split.

kill criterion: Arm B below Arm A on the test split (point estimate), in which case curation survives only as Arm C if C >= A + 1. Stop before running if the BM25 channel is not repaired (P1: dead RediSearch prefix), because Arm A cannot be built without it.

what a pass unlocks: the H3 curate step ships as the Spec-time selector against a control that matters; a fail makes anchored hybrid the default read at Spec time and saves the curator's cost. Moves B7 (lead) and adds evidence to B23 (RRF as baseline, strengthened by lexical anchoring).

cost (runs, tokens, people-days): M. Three arms over the H3 task set (dev plus test), executor and judge runs per arm; curator calls for B and C. Rough estimate for 200 test + 100 dev tasks: 900 executor runs plus 600 curator calls; tokens depend on the budget chosen and are estimated at 20M to 40M. About 3 people-days to add Arms A and C to the H3 harness. Budget: policy unset.
