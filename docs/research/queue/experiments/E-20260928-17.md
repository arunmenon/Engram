claim: Typing items from connected engineering tools onto the ontology's shared types is more accurate, and cheaper, when the typed Choice's menu is a governed PDLC thesaurus (one preferred label per concept, each tool's issue types, statuses, labels and link names as alternative labels, a one-line scope note) than when the menu is the raw target type names; and exact label lookup in the thesaurus resolves a large share of items before any model runs. Source: N-SURVEY-20260928-27 (Talisman, Ontology Pipeline, 2026): a practitioner framework that says a controlled vocabulary and thesaurus must precede the ontology; it gives no measurements, no baseline and no case study, and the author sells the framework. N-SURVEY-20260928-26 (synthesis) proposes shared kinds with per-tool bindings; N-SURVEY-20260928-20 notes Cognee's canonical renaming on match, also unmeasured. The evidence is opinion grade: this spec tests a design idea, it does not replicate a result. It is the run's exploration slot: cheap (S), and a surprising result either way would change the binding design before the heavier G7 work in E-20260928-15 is built.

arms (same items, same pinned Choice model, same scorer; arms differ only in the menu and the lookup step):
- A (raw names): typed Choice over the shared target types, each given by its type name only.
- B (thesaurus menu): the same Choice, each option rendered as preferred label, alternative labels and scope note from the thesaurus.
- C (lookup first): exact, case- and whitespace-normalised match of the item's raw type, status and label strings against the thesaurus alternative labels; if every string resolves to one concept, the item is typed by lookup with no model call; otherwise B.

metric: type accuracy against the gold shared type (primary, G7); share of held-out items resolved by lookup alone in C; tokens, cost and p95 latency per 1K items per arm; upkeep hours per month (from the drill below); same-item F1 (G13) as a secondary metric only if E-20260928-14's matched-pair set has been frozen by then, otherwise reported as not run.

predeclared margin: positive if B minus A is at least 3.0 points with the 95% clustered interval excluding 0, or if C's lookup share is at least 40% and C minus B has a one-sided 95% lower bound above -2.0 points; in either case upkeep must be at most 4.0 hours a month. Bounded negative if the one-sided 95% upper bound of B minus A is below 3.0 points and C's lookup share is below 40%. Upkeep above 4.0 hours a month recommends folding the thesaurus into the ontology gate whatever the accuracy result.

sample size and power note: 300 held-out items, 100 per tool. Items sharing the same raw type and status strings share much of their outcome, so the clustering unit is the raw string combination, and a design effect of about 2 is assumed. With a discordant rate of about 0.10, SE(B - A) = sqrt(0.10 / 300) x sqrt(2), about 2.6 points. At a true gain of 8 points, P(pass) = Phi(8 / 2.6 - 1.96) = Phi(1.12), about 87%; at a true gain of 3 points, about 21%. At a true gain of 0, the bounded negative on B minus A is reached about 31% of the time. The lookup share is a proportion over 300 items: at a true 40% its clustered SE is about 4 points, so values between about 32% and 48% should be read with their interval. The card's 3-point rule is kept as the practical margin; small true effects will mostly read as inconclusive, which is declared.

kill criterion: the thesaurus layer is killed on the bounded negative (upper bound of B minus A below 3 points and lookup share under 40%), and folded into the ontology gate if upkeep exceeds 4 hours a month. Invalid (rerun, not a verdict): the thesaurus built with any post-cutoff string, gold labellers overlapping with thesaurus builders, gold inter-annotator agreement (Cohen's kappa) below 0.7 before adjudication, or the token cap hit.

what a pass unlocks: the binding design for gateway component 15 (per-tool bindings through a governed thesaurus rather than straight onto types), the menus for the G7 and G13 Choices, and a deterministic lookup step that removes model calls; input to E-20260928-15 (bind-time typing) and E-20260928-16 (gated type admission), where new labels would first land as alternative labels. The register holds no belief on controlled vocabularies, so a pass proposes a new belief rather than moving a grade.

cost (runs, tokens, people-days): thesaurus build, 2 people x 2 days (card); gold labelling of 300 items by 2 other engineers, 2 days each; harness, 2 engineer-days. Model tokens about 1.4M (A and B at about 1.5k tokens per item, C fewer). Cost S.
