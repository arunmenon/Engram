claim: On our held-out set, (1) adding a "none" option to a listwise choice ranker, with the probability cutoff and serving policy held fixed, lowers gold retention on answerable queries by at least 0.05; (2) a separate pre-retrieval recall/no-recall gate in front of the ranker raises correct abstention on unanswerable prompts by at least 20 points while keeping gold retention within 0.02 of the ungated ranker; (3) opt-out compliance is measured separately, and the model gate earns its call on opt-out only if it beats a deterministic opt-out rule.

arms:
- Ranker factorial (none option x cutoff), same choice call, same pool, same order, same serving policy (serve up to 5 memory options that clear the cutoff, ranked by probability):
  - A00 (no none, no cutoff): top 5 memory options served; at least 1 always served (shipped Hindsight design).
  - A01 (no none, cutoff 0.05): memory options with probability >= 0.05, up to 5; empty if none clears.
  - B10 (none, no cutoff): top 5 memory options served, except serve nothing when the none option is the argmax.
  - B11 (none, cutoff 0.05): memory options with probability >= 0.05, up to 5; serve nothing when none is the argmax or no memory option clears (shipped jevmem design).
  - The none effect is estimated at each cutoff level (A00 vs B10, A01 vs B11); the cutoff effect is estimated separately (A00 vs A01). Losses from the cutoff are never attributed to the none option.
- Gate arms (ranker fixed at A00):
  - C: a yes/no model gate before retrieval ("Does answering this prompt need project memory? False if the prompt asks not to use memory."); on no, serve nothing; on yes, serve A00's result for that query (reused, not recomputed).
  - R: deterministic opt-out rule: a fixed, versioned phrase list ("without using memory", "don't use memory", "ignore project memory", and the variants in `optout_rules.txt`, frozen before prompts are written) serves nothing on a match; otherwise A00.
- Shared: pool = top 60 from H2's fusion (RRF k=60), candidate text truncated to 120 tokens, same seeded candidate order in every arm; ranker and gate use the same pinned decision model; the answerer and the judge are pinned models from different model families from each other and from the decision model; the judge sees only the prompt, the answer and the reference (or "unanswerable" label), never the arm, the served set or retrieval metadata. Order control: on a 100-query subset, A00 and B11 are re-run with two more seeded candidate orders.

metric: primary: (a) gold retention on answerable queries = |served intersect gold| / |gold|, 0 when nothing is served; (b) correct abstention on unanswerable prompts (the answerer declines or says unknown, per the blinded judge); (c) opt-out compliance on opt-out prompts (nothing served). Each is a separate endpoint; nothing is pooled. Secondary: empty-result rate on answerable queries per arm, end answer accuracy on answerable queries, gate latency p95, decision-model tokens, order sensitivity.

predeclared margin: none_harms_ranker: (A00 - B10) >= 0.05 with the 95% cluster-bootstrap interval excluding 0 (none effect without cutoff); (A01 - B11) is reported as the replication at the shipped cutoff. gate_earns_call: (abst_C - abst_A00) on unanswerable prompts only >= 0.20 with the 95% lower bound >= 0.10, AND (ret_A00 - ret_C) <= 0.02 point with one-sided 95% upper bound <= 0.04. optout: gate_beats_rule_optout requires optout_C - optout_R >= 0.10 with 95% lower bound > 0; if optout_R >= 0.95 the rule is adopted for opt-out and the gate is judged on unanswerable abstention alone.

sample size and power note: at least 300 answerable, 150 unanswerable and 60 opt-out prompts, clustered by source conversation or project (at least 30 clusters, and at least 15 clusters containing unanswerable prompts). Retention: the none effect at fixed cutoff differs only on queries where the none option is argmax; if that happens on about 6% of queries (Hindsight reported 35 of 200, unverified here), the SE of the paired retention difference is about 0.015, so a 0.05 loss is resolvable. Abstention on unanswerable alone: 150 prompts with paired discordance near 30% gives an SE of about 0.045, enough for a 20-point gain at about 80% power but not a 10-point one, hence the lower-bound rule. Opt-out: 60 prompts bound a zero-failure compliance rate at about 5% (B21), which is why a deterministic rule reaching 0.95 is enough to adopt it. Clustering widens all intervals; the verdict reports the effective number of clusters.

kill criterion: none_harmless: ci95_high(A00 - B10) < 0.02. gate_not_worth_call: ci95_high(abst_C - abst_A00) < 0.10 on unanswerable prompts. Stop before running (not a result) if the P3 held-out split lacks any class at the minimum counts, gold ids or reference answers are found in the memory store snapshot, model separation is violated, or any pin is missing.

what a pass unlocks: fixes where the empty result lives (a gate, not the ranker) for P0 F10's empty-admission semantics; separates the cutoff decision from the none-option decision; tells H5-rerank that its ranker never carries a none option; decides whether opt-out needs a model call at all.
