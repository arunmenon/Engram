claim: On a replayed task stream with guardrail blocks, outcome-gated lesson promotion lowers the active guardrail's trigger rate by at least 25% relative to memory off over the stream while a held-out monitor that never feeds memory shows no such fall, and excluding writes from blocked episodes removes less than half of that fall.

proposed experiment: Arm A = memory off. Arm B = outcome-gated promotion using Beacon's rule (candidate only if task_success >= 0.50 AND the mean of three yes/no quality scores >= 0.60), auto-approved for the experiment so promotion is not human-limited. Arm C = Arm B with every write whose source episode contained a block or denial excluded. Arm D = Arm B with promotion scored on counterfactual success (would the task have succeeded absent the block) instead of raw success. Active guardrail and a held-out monitor of a different design run in all arms; only the active one's outcome feeds memory. Dataset: H4's replayed task stream with `task.outcome` events, seeded with tasks where a guardrail blocks a useful action, task mix held flat across rounds. Metrics: active trigger rate per round, held-out monitor rate per round, divergence between the two, task success, and a blind audit of promoted lessons for "how to get past a check" content. Predeclared margins as in the claim. Kill: B's active trigger rate within the noise floor of A (B18's risk does not appear at our scale; keep only the passive check), or C removes at least half the fall (exclusion suffices, and D is unnecessary).

Evidence: Mallen's essay is qualitative ("No quantitative estimates"), argues memory is the weaker case but real, and predicts that filtering blocked trajectories "gives minimal benefit" because unblocked successes can still encode how not to get blocked; the memory analogue is the note's inference. Beacon's task_success floor of 0.50 was added after issue #649, where a failed trace scored 0.27 / 0.86 / 0.69 (mean 0.6067) and passed a mean-only gate; the repo has no memory-quality metrics.

why it matters for us: R5 treats a memory that learns from outcomes as a self-improvement loop, and B18 says it can learn to route around guardrails without intent but nobody has measured it. The result decides whether the governance check stays a dashboard number or becomes a promotion rule with counterfactual scoring.
