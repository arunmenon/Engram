claim: On bug-fix tasks whose correct fix depends on a past decision recorded only in earlier sessions or decision records, a coding agent with a prompt-time memory hook needs at least 30% fewer corrections to pass a hidden test than the same agent with that history merely reachable on disk.
proposed experiment: Arm A = coding agent (one fixed agent and model) with the history reachable but not pointed at; arm B = same agent with our memory hook injecting recalled decisions at prompt submit; optional arm C = Hindsight's coding-agents plugin as an external reference. Dataset: 40 or more tasks built from our own repositories in the sdebench pattern (a past decision on a limit, invariant, ordering or mapping; a bug report whose obvious fix contradicts it; a hidden test), plus 10 reversed-decision tasks where the recalled decision is stale. Metric: interventions to pass (cap 5), cost, turns; stale-decision tasks scored separately. Predeclared margin: B reduces total interventions by at least 30% vs A over 3 repeats, with a task-clustered bootstrap interval excluding 0, and B is not worse than A on the reversed-decision tasks by more than 1 intervention per 10 tasks. Kill: reduction under 15%, or B worse on reversed-decision tasks beyond the margin.
why it matters for us: R6 needs a benchmark that measures memory where engineering agents feel it (corrections avoided, cost), and the only data so far is vendor-planted; our own tasks give an independent check. It also tests the R5 risk that recalled decisions go stale, which the vendor benchmark omits.
