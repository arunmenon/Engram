claim: With the correct answer absent and an explicit none option, Jev chose none only 7% of the time on two-step arithmetic menus (99% when the answer was present); the label wording did not matter (None 7%, Other 9%, None of the above 6%). The same model asked per candidate with Boolean verification rejected all wrong candidates 99% of the time, and a threshold fit on 20 development problems per task raised Choice rejection to 79% at 97% answer-present accuracy (arXiv 2609.39496). Time calculation and capacity rounding showed the same gap; symbolic tasks such as state tracking did not. An independent 37-dataset study confirms Jev Choice probabilities are well calibrated overall (pooled ECE 0.028) but binary thresholds need local fitting (arXiv 2609.37647), which is why a fitted threshold works.

proposed experiment: Refines PC-20260927-03 (per-candidate yes/no vs one Choice, scored on ranking when several candidates are relevant) by adding the case it does not cover: no candidate qualifies. Complements PC-20261001-02 (pre-computing dates and versions), which changes the input; this changes the question shape, and the two can share data. Data: at least 200 staleness items from our frozen PDLC corpus, each a question plus 3 to 5 stored memories, half with exactly one still-current memory and half with none current (the current one removed, as in the paper's paired design), split into date/version-dependent and text-only strata. Arms, same items, pinned Jev version: (A) one Choice over the memories plus "none of these is current"; (B) one Noul per memory "is this still current as of <date>?", none current when all fall below a fitted threshold; (C) A with a threshold on the top option's probability fit on a 20%-of-items development split; (D) A on state with dates and versions pre-computed in code (PC-20261001-02 projection). Metrics: correct-none rate on the none-current half, correct pick on the one-current half, per stratum with Wilson 95% intervals, calls and cost per item, p95 latency. Predeclared: B or C reaches at least 30 points higher correct-none rate than A on the date/version stratum, losing no more than 3 points of correct pick. Kill: if A's correct-none rate on our data is within 10 points of B, keep the single Choice call.

why it matters for us: When an engineer's agent asks memory "what is the current decision on this?", the honest answer is sometimes "none of what we have is current". One study shows Jev, asked the obvious way, almost never says that when dates or version numbers decide the answer, so the agent would act on an outdated note. Asking about each note separately, or setting the cut-off from our own examples, fixed most of it in that study at little or no extra cost. This cheap test tells us which question shape to build into our memory checks before we build more of them.
