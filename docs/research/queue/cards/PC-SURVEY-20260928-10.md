claim: Graphiti and Cognee both expose a choice between prescribed types, prescribed types with unmatched items kept (annotate), and learned types. Neither measures the choice. EDC's canonicalisation kept 200 relation types at 0.956 precision where CESI kept 280 at 0.724. EvoOntology's task-score gate was its largest ablation (-11.2 without it). No paper tests type admission on engineering artifacts.

proposed experiment:
- **Setup.** Use H7's seeded project history, extended with team-specific artifacts that the PDLC core does not name (runbooks, feature flags, incidents, about 60 records).
- **Arms.**
  - A: strict PDLC core types (unmatched dropped).
  - B: annotate mode (unmatched kept as generic Entity, flagged).
  - C: learned types, ungated.
  - D: learned types admitted through canonicalise-first then a typed Choice `same_as(k)` or `new`, with the new type kept only if H7's question accuracy on a validation split rises by at least 2 points.
- **Metrics.** H7's exact-answer accuracy per class (supersession, completeness, negation) on a held-out split, plus questions about the team-specific artifacts; type count after ingestion; and extraction cost.
- **Kill criterion.**
  - B is within 2 points of D on every class: ship annotate mode and no admission gate.
  - C ends with more than twice the types of D at no accuracy gain: never ship ungated learning.
  - A beats B on the core classes by more than 3 points: unmatched items hurt, so ship strict.

why it matters for us: This answers the part of Palantir's approach we should not copy (a hand-modelled type set) with a measurement rather than a preference. It also decides whether the ontology evolves from agent traffic this quarter or stays a fixed amendment.
