claim: On TWIST Track B (161 human-validated items), a Jev noul "does this draft contradict retrieved memory item X?" over the same flat-RAG top-k reaches hard-negative specificity at least 0.10 higher than the flat-RAG GPT-4o flagger (0.57) while keeping contradiction recall within 0.10 of it (0.97).
proposed experiment: Arm A = the paper's flat-RAG flagger re-run with our retriever and an LLM judge (GPT-4o, as published, plus our default LLM); arm B = same retrieved top-k, one Jev noul per retrieved memory (contradicts, with explicit true/false criteria including the acknowledged-pause and change-question hard-negative cases), flag if max noul >= t with t fitted on a 40-item split and frozen; arm C (optional) = arm B with an open-weight decision model (Laya or Jeeves no-think) behind the same client. Dataset: TWIST Track B v1.0 frozen key (github.com/subratpanda/twist-benchmark at 19f9c70), 40 items for threshold fitting, 121 held out. Metrics: CR, AS, HNS, GCR (flag plus a correct top-3 evidence turn) on the held-out 121, bootstrap 95% intervals; cost and p50 latency per item; repeat each Jev call twice with canonical option order and report disagreement (N-20260930-01 found 4.3% repeat-call flips). Predeclared margin: B wins if HNS_B - HNS_A >= 0.10 and CR_A - CR_B <= 0.10 and GCR_B >= GCR_A - 0.05. Kill: if arm B's HNS interval overlaps arm A's and CR drops more than 0.10, drop the Jev contradiction check at this stage and keep the LLM flagger for pre-action checks. Scoring is structural (no LLM judge), as in the paper.
why it matters for us: The PDLC benchmark's "notice a changed requirement before acting" task needs a contradiction check that fires on real reversals and stays quiet on consistent revisions; TWIST shows current flaggers trade one for the other, and no one has measured a System One model on it. The result decides which implementation sits at the linking stage for contradicts links and pre-action checks (R9, R10), on public data, before we build PDLC items.
