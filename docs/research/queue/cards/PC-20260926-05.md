claim: At a matched token budget, task-conditioned curation at Spec time does not exceed anchored hybrid retrieval (top BM25 items first, then RRF fill) by 3 or more points of spec-task success.
proposed experiment: Arm A = anchored hybrid retrieval: top lexical hits placed first, then RRF(vector, BM25, entity) fill to budget; Arm B = H3 task-conditioned curation (LLM or decision-model curator) at the same token budget; Arm C = Arm A reranked by the curator's scores (planner as rerank feature). Dataset: the H3 spec-writing task set on frozen repositories, split dev/test with the test split untouched until the final run. Metric: spec-task success judged by the fixed harness, with paired bootstrap CIs; also evidence recall where gold evidence exists. Predeclared margin: Arm B must beat Arm A by >= 3 points with the paired interval excluding zero to ship curation as the selector. Kill: Arm B below Arm A on the test split, in which case curation survives only as Arm C if C >= A + 1.
why it matters for us: R3 is about selecting sufficient evidence within a bounded budget, and B7's support comes from a comparison against write-time distillation, not against strong retrieval. A controlled negative result elsewhere (planner 34.19% vs anchored hybrid 36.18%) makes the strong-retrieval arm mandatory before we adopt curation.
