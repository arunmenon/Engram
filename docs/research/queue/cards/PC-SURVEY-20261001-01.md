claim: The paper our PDLC design cites for calibrated per-link confidence (Trust-Aware Multi-Agent Traceability, arXiv 2606.17203) reports no calibration measurement; its confidence is the LLM's own five-band score. Filtering links by that confidence cut conflict-aware path completeness from 100.00% to 33.64% (36.12% without the conflict detector) on 535 automotive artifacts, while a creation threshold of 0.7 gave the best link F1 (P 0.782, R 0.818, review queue 23 links per subsystem). Separately, decision models compress graded scales: Jev 1.13 used 95.9% of the gold level spread at 2 levels but 54.5% at 14 (arXiv 2609.38827), so asking for confidence bands loses information that a yes/no probability keeps. TraceDev (arXiv 2607.18886) shows a completeness walk over trace links lifts end-task success (28.37% to 47.19% without vs with its validator), so missing paths cost real work.

proposed experiment: Refines PC-SURVEY-20260928-06 (which model decides IMPLEMENTS links, scored on precision and F1) and H7 (traversal over typed PDLC edges, which assumes the edges exist). The new question is the threshold policy and its completeness cost, across all three link types. Data: the same SpecMine-derived pair set as PC-SURVEY-20260928-06, extended to REFINES (design section to requirement) and VERIFIES (test to requirement), at least 150 labelled candidate pairs per link type, two labellers, kappa reported; a calibration split (40%) and a test split (60%) by repository. Arms, same candidates from the same retrieval top-10: (A) LLM verbalised five-band confidence with the paper's bands and criteria, written at 0.7; (B) A with its threshold refit on the calibration split; (C) Jev Noul probability for "does X implement / refine / verify Y?", threshold fit on the calibration split (neutral option names); (D) an open-weight decision model (Bongard or decider-2b) with the same questions and fitting. Metrics per arm and link type, on the test split: precision at the fitted threshold, link recall, review-queue size, orphan rate (share of requirements with no IMPLEMENTS path to code or no VERIFIES path to a test, compared with the gold graph), ECE, cost per 1,000 links. Predeclared: C or D beats B on orphan rate by at least 10 points at equal precision (within 0.02). Kill: if B is within 5 points of C and D on orphan rate at equal precision, keep the cheaper of B and C and drop the band design question.

why it matters for us: The memory we are building for product teams has to answer "which requirements have no code or no test yet?". If it only keeps links it is sure of, it may quietly drop most of those trails, and agents would believe work is missing when it is not, or miss work that is. The design we drafted assumes a published method solves this, and the primary read shows it was never measured. This test tells us which way of scoring links keeps the trail intact at the precision we need, and whether Jev or a model we run ourselves can do it cheaply.
