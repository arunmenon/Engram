claim: In SKILL-KD's ablation, contrastive success/failure evidence alone (Pairwise 59.0, Batch 59.4) did not beat single-source induction (Student-only 60.1). The +6.7-point gain to 66.8 came from adaptive validation and drift-aware consolidation. Single run, not coding agents.

proposed experiment: Refines H6. H6 compares comparative vs single-trajectory induction with no factor for acceptance. Run it as a 2x2 on the same Episode set: evidence (single success vs comparative, MGM Phi_RM/Phi_CH style) x acceptance (commit directly vs commit only if the induced Workflow beats the current one on a held-out split with the same task_key). Metrics: H6's re-use success and instance-specific-value rate, plus Workflow length. Report the interaction. Predeclare: if the acceptance main effect exceeds the evidence main effect, build the validation gate first and keep single-trajectory induction.

why it matters for us: B15 rests on one system. Without the acceptance factor, a win for the comparative arm cannot be told apart from an implicit validation effect. That matters because MGM's archive-and-select loop is itself a validation gate. The extra arms use the same Episodes and judge.
