claim: Explicit PR-issue references are misaligned in 13.6% of SWE-bench Verified pairs; a frontier multi-agent checker detects misalignment at 88.11% to 92.12% binary accuracy for $0.08 to $0.23 per link (arXiv 2607.28587). Fine-grained PR-issue alignment has human kappa 0.575, and fine-tuned 3B to 7B models reach 62.75% accuracy but 34.44% macro-F1 (arXiv 2609.01087). No study found tests a System One model on this decision. SpecMine (arXiv 2608.25202) supplies 5,992 spec-touching PRs from 581 repositories and 98,574 Kiro requirement / design / task files under CC BY 4.0. Independent evaluation shows Jev about 44x cheaper than the best LLM but 11.6 macro-F1 points behind, and a confidence cascade matching the LLM at 27% to 56% of its cost (arXiv 2609.24574).

proposed experiment: Refines H7, which assumes the typed IMPLEMENTS and REFINES edges exist and tests only traversal over them; this tests who can create them, the CTO's priority 3 slice with a System One model deciding the links. Data: 300 (requirement or design section, PR) candidate pairs from 6 to 10 SpecMine Kiro repositories, half co-change or referenced pairs and half hard negatives (same repo, same period, not linked), two human labellers with a 3-way label (implements / partial / no) and kappa reported. Arms, same pairs and same rubric with neutral option names (see PC-SURVEY-20260928-04): (A) Jev Noul "does this PR implement this requirement?"; (B) an open-weight decision model self-hosted (Laya or decider-0.8b); (C) a fine-tuned ModernBERT-large on a separate 1,500-pair training split from other repos; (D) an LLM checker (single Claude call with the PAIChecker taxonomy); (E) cascade A then D below a confidence threshold fit on a calibration split. Metrics: precision at recall 0.8, macro-F1 on the 3-way label, ECE after temperature refit, cost per 1,000 links, p95 latency. Kill for System One at this stage: A, B and C all more than 10 F1 points below D, and E not within 2 points of D at under 50% of D's cost.

why it matters for us: The context graph's value for product work rests on knowing which code change delivers which requirement. Today the only measured way to check that costs several cents per link using frontier models and sends our customers' code outside. If Jev or a model we host ourselves gets close at a fraction of the cost, the graph can be kept up to date on every pull request and the text stays in-house.
