claim: Where a memory-poisoning defense sits predicts its benign cost: write-time defenses showed 0.000 false quarantine rate on attack-free traffic while a read-time quarantine defense falsely quarantined 33.6 % of legitimate memories (arXiv 2609.22818). Separately, a write-time prompt rule cut injection into Claude Code memory for image and PDF carriers but not text (ISR 96.7 % to 84.4 %) and did nothing once memory was poisoned (C-ASR 96.7 % to 96.7 %) (arXiv 2609.13889). Neither placement alone is shown to be sufficient.

proposed experiment: Refines H10(b), which tests only a serving-path gate. Same planted set (about 40 instruction-bearing lines, add PMPA-style "store this rule" payloads arriving via tool results, text carrier) and a benign set of at least 149 independent engineering memories from real project history. Three arms, same classifier and threshold: (A) gate at extraction write time; (B) gate at serving time (current H10b); (C) both. Metrics: planted lines served (block rate), benign false-block rate with one-sided 95 % upper bound, served tokens, p95 serving latency, and for arm A the rate at which poisoned lines already in the store before the gate was enabled are still served. Kill for A as a replacement for B: A leaves pre-existing poisoned lines served. Kill for B: false-block upper bound above 2 % (H10's own threshold).

why it matters for us: B24 rests on 44 author-written lines with one placement. The external evidence says benign cost depends on placement and that write-only defenses cannot repair an already poisoned store, so the choice of placement is the decision, not just the classifier threshold.
