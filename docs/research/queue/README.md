## Rules

- **Append-only, one file per event.** Nobody edits another agent's file. A card's current status is the newest `decisions/PC-….<status>.json` for that id; no decision file means `proposed`.
- **Status vocabulary:** `accepted | merged | rejected | withdrawn`; `carded` is implied by the presence of `experiments/<id>.md` referenced from the decision file.
- **Every decision file carries** `{id, status, decided_by, decided_on, reason, carded_as?, merged_into?}`.
- **`index.json`** at the root is regenerated by whichever agent ran last, from `cards/` plus `decisions/`. It is a convenience, never the source of truth.
- **Write with conversion disabled** (plain `text/markdown` or `application/json`); never let Drive turn a file into a Google Doc.
- **List folders by parent id**, never by title search; Drive's search index lags uploads by minutes.
- **Mirror:** the delta job (or a cloud session) copies the whole tree into this directory every Monday and commits. Git is the archive and the review surface; Drive is the bus.
- **Deadlines:** a card with no decision file after 14 days appears in the weekly delta as overdue.
