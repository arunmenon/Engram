## Contradictions and qualifications (read first)

1. **B23 (working), partial contradiction.** N-SURVEY-20260928-08 (Bruch, Gai, Ingber, arXiv 2210.11934): RRF is "sensitive to its parameters". RRF(60,60) was not the best RRF setting on any dataset reported, and a normalised convex combination beat it on all six datasets reported (MS MARCO NDCG@1000 0.425 vs 0.454; NFCorpus zero-shot 0.312 vs 0.327), with the weight tuned on under 5 % of training queries. RRF k=60 is still an acceptable floor. It should not be the only fusion arm in H2. Card PC-SURVEY-20260928-03.
2. **B24 (lead), qualified, not contradicted.** N-SURVEY-20260928-01 (arXiv 2609.22818): on attack-free LoCoMo traffic, write-time defenses had a 0.000 false quarantine rate, but a read-time quarantine defense falsely quarantined 33.6 % of legitimate memories it adjudicated (up to 106 in one conversation) and cost -4.4 pp accuracy (CI [-9.0, -0.05]). B24's 0/22 false blocks comes from a read-time (serving) gate tested on 22 benign lines. The mechanisms differ (contradiction reranker vs injection classifier), so this does not refute B24. It does show that 22 lines cannot reveal a serving-time false-block problem. N-SURVEY-20260928-03 (PMPA) shows write-time rules alone do not help once memory is poisoned. Card PC-SURVEY-20260928-01.
3. **No contradiction to B25 (firm).** Two independent sources support it with measurements: N-04 (the Validator was bypassed in 100 % of attacked trials, but unsafe actions were 0 % because an external policy oracle made the authorisation decision) and N-05 (PACT: argument-level provenance, 100 % AgentDojo security with 8 to 16 pp more utility than CaMeL).

## R7 Interoperability and coordination contracts

**Found:**

Normal compression gives 100 % deactivation and 54.2 % forbidden action. This extends Governance Decay (2606.22528, already in the landscape) with the field decomposition and endpoint-control arms.

- N-08 Bruch et al. (above).
- MemSecBench (N-02, filed under R8) also bears on the swap test. Under the same harness and model, swapping the memory backend changed end-to-end attack success by up to about 14 pp in either direction ("No memory backend is uniformly safer"). A swap test should include security behaviour.

**Screened, no note:**

Below vendor-benchmark strength for a swap-test claim. It is the closest existing artifact to B22's swap test and worth rechecking when a v2 appears.
