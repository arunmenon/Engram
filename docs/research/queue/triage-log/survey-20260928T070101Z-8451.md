# Survey summary, run survey-20260928T070101Z-8451 (pillars R9, R10)

Priorities served: 1 (System One models at memory stages), 2 (open-weight System One models), 3 (PDLC ontology and trace links), 4 (benchmark design, secondary). Budget used: 15 of 25 primary reads, 8 of 8 notes, 3 of 4 cards. No watch requests were open, so none answered.

## Contradictions (first)

1. **Laya's published calibration does not hold on independent data.** Laya's model card (v0.3.20, https://huggingface.co/convaiinnovations/laya) claims ECE 0.081 after temperature refitting, measured on its own typed-decisions set. An independent pre-registered evaluation on 18 human-labelled tasks (arXiv 2609.24574) measures Laya-0.4B median ECE 0.275, more than three times higher. Contradicts the vendor claim; supports B14 ("vendor calibration is claimed, not shown"). Note N-SURVEY-20260928-11. Serves priority 2.
2. **A 0.8 confidence threshold is not a safe gate when the state contains memory text.** Our planned gates (discovery plan H5, H10; the Beacon-style Jev-scored write gate in N-CAT-10) assume a high-confidence Jev answer can be accepted without review. JevAdvBench (arXiv 2609.31142) shows one unverified opinion appended to the state pushes 38.0% [31.1, 44.0] of >= 0.8 answers below 0.8 (0.5% on re-run) and flips 12.1% of decisions; JevOut (arXiv 2609.30243) finds high-confidence (p >= 0.7) wrong answers in 45.1% of successful flips. This contradicts the design assumption, not a graded belief (no R9 belief is on file). Note N-SURVEY-20260928-09, card PC-SURVEY-20260928-05. Serves priority 1.
3. **Schema-valid output is not rubric-following output.** Type-error rate stays 0% while yes/no option names reverse decisions (AUC 93.8% to 23.2%; hosted Jev .8146 to .5806; arXiv 2609.26758). Any assumption that Jev's typed interface guarantees correct reading of our rubric is contradicted. Note N-SURVEY-20260928-10, card PC-SURVEY-20260928-04. Serves priority 1.
4. **Explicit PR-to-issue references are not gold links.** 13.6% of SWE-bench Verified PR-issue pairs are misaligned (arXiv 2607.28587). The PDLC layer draft does not state this assumption, but any plan to use "fixes #N" references as IMPLEMENTS ground truth should not. Note N-SURVEY-20260928-14. Serves priority 3.

Not memory tasks. Priority 2.

## R10 The context graph and its ontology

**Looked for:** (1) trace link recovery with LLMs and calibration of link confidence; (2) whether a small model decides trace links as well as a large one; (3) schema and state evolution beyond EvoOntology; (4) ontology-guided extraction for engineering artifacts; (5) data to seed our PDLC memory benchmark.

**Found:**
- SpecMine (N-SURVEY-20260928-13): the first public corpus with requirement / design / task files (Kiro layout, 98,574 files) and 5,992 spec-touching PRs with full commit history, CC BY 4.0. Best seed found for H7's typed records and for the PDLC benchmark. Priorities 3 and 4.
- IMPLEMENTS-link decision accuracy (N-SURVEY-20260928-14): explicit references wrong 13.6% of the time; frontier multi-agent checker 88% to 92% at $0.08 to $0.23 per link; fine-grained human kappa 0.575; small fine-tuned models match large prompted ones on accuracy, weak on minority classes; classic requirement-to-design prompting at precision about 0.5. No System One arm anywhere. Priority 3, card PC-SURVEY-20260928-06.
- EvoWiki / CrossMeet (N-SURVEY-20260928-15): an explicit supersession protocol (Active / Overturned, one active version, provenance anchor) is worth about 9 pp on evolving-decision QA (ablation 60.09 to 51.46). Supports SUPERSEDES as a write-time decision. Priorities 3 and 4.
- Local open-weight labelling of commits (N-SURVEY-20260928-16): 24B model F1 0.645 vs keyword 0.399; 122B not better; corpora without negatives invert rankings. Rule for our benchmark: always include negatives. Priorities 4 and 2.
- Nothing new with numbers found on calibrated confidence for trace links; Trust-Aware Multi-Agent Traceability (2606.17203, in the September landscape) remains the only source.

**Read, no note:**
- SCOPE and SCION (arXiv 2607.21610): schema induction benchmark from 24 IE sources; open Qwen3-8B variant (SCION-RL) beats GPT-5.2 LLM-only on all four schema metrics (for example Graph F1 0.8228 vs 0.7331), $0.12 per source. No evaluation of schema evolution with new documents and no engineering artifacts; below the applicability bar for a note. Useful if we ever induce node types from a customer's documents.
- Jev in the Wild (arXiv 2609.30216): 2,170 public Jev projects; "Context & Memory" 77 projects (3.5%), "Search & Data" 120 (5.5%), "Dev Workflows" 218 (10.0%), "Code Quality" 90 (4.1%); classification by a GPT-6 Luna Max agent with a second agent review. Usage map only, no quality results; recorded here for priority 1 ("who uses them where").
- TraceLLM (arXiv 2602.01253): folded into N-SURVEY-20260928-14.
- Decision Hijacking (arXiv 2609.28613): folded into N-SURVEY-20260928-09.
