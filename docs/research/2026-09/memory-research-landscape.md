# Agent-memory research landscape, March–September 2026

**Date:** 2026-09-25
**Scope:** what has appeared since the January–February 2026 research pass (`docs/research/*.md`, dated 2026-02-07 to 02-13) that bears on Engram's ingestion, projection, extraction, consolidation, scoring/forgetting, retrieval, entity resolution, ontology, evaluation or the PDLC use case.
**Method and limits:** arXiv, HF Papers, Semantic Scholar, letta.com, mem0.ai and openai.com are blocked from this environment. Paper details come from search-engine excerpts of arXiv abstract pages; GitHub release pages were fetched directly. Dates are arXiv submission dates as quoted; where only a month was recoverable it is given as such. Numbers are as reported by the authors (self-reported unless stated). Every item carries the URL that surfaced it. Nothing here was reproduced.

Legend for *Engram fit*: **(a)** drop-in improvement to an existing component; **(b)** design change; **(c)** context or benchmark, no code implication.

## 0. What changed since February, in five lines

1. **Provenance-first memory is now a published category**, not an Engram differentiator: Eywa, Agent Zero Memory, MemIR, "Stored Is Not Supported", MemTX, MAP-Graph, AkasicMEM all separate raw evidence from derived claims and gate what may be asserted. Engram's architecture is validated; its *implementation* is behind (see the [catalogue](judgment-points-catalogue.md)).
2. **Belief lifecycle and revocation** (MemTX, TARL, TEPA, Nous) is the most concrete gap: Engram has CONTRADICTS/SUPERSEDES edge types but no state machine, no cascade along DERIVED_FROM, and no code creating Belief nodes.
3. **Graph memory has to prove lift.** A graph with almost exactly Engram's pruning formula lost to a flat vector baseline on LongMemEval at matched budget (§1.17). MemDelta showed an 11-point "graph wins" result reversing to −1.2 when only the embedding model changed. Publish nothing without a one-variable protocol.
4. **Procedural memory evolution is where the 2026 gains are** (Recuris, TRACE, Memp, HyperSkill, SkillSmith): validation-gated, failure-localised, contrastive updates to skills/workflows with success statistics — exactly the Workflow/BehavioralPattern layer Engram declared and never implemented. See [rsi-positioning.md](rsi-positioning.md).
5. **Software-engineering memory now has its own literature** (ProjectMem, EA-Graph, MOOSEDev, TraceDev, DreamBench-SWE). Typed supersession graphs beat vector search by 70+ points on exactly the questions a PDLC memory must answer. See [pdlc-memory-layer.md](pdlc-memory-layer.md).
