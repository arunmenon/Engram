# Evidence catalogue: agentic memory, Jev, RSI

A systematic catalogue of every piece of evidence behind the Trends tab of the Self-Improving Agents hub (https://claude.ai/artifact/HoJHLMXZE8vrnvNdh8gEcz). It was built on 2026-09-26 to feed a session that is tuning a memory stack.

It covers 5 trends and 26 evidence items. Behind those are 86 X posts (the evidence posts plus their threads, quoted posts and linked posts), 2 X Articles, 5 arXiv papers (downloaded), 4 GitHub repos (read at pinned commits), about 15 web pages, and 26 images (transcribed).

## Where to start

| If you want... | Read |
|---|---|
| The answer: what to change in a memory stack, with the evidence strength for each point | `memory-stack-synthesis.md` |
| One file to paste into another session | `memory-stack-evidence-bundle.md` (the synthesis, the ledger and every source note concatenated) |
| Each trend, then each evidence item with the full post, thread, quotes, links and images | `evidence-ledger.md` |
| The deep write-up of one source | `sources/<name>.md` (the index is below) |

## Layout

```
evidence/
  README.md                       this file
  memory-stack-synthesis.md       findings by design decision (write, read, update, consolidate, gate, eval) + contradictions table
  evidence-ledger.md              trend -> evidence -> full X context (generated by bin/evidence_ledger.py)
  memory-stack-evidence-bundle.md single-file handoff (generated)
  sources/                        one detailed note per external source (fixed template)
  papers/                         arXiv PDFs + abstract pages
  media/                          every image attached to evidence posts and articles
  raw/                            machine-readable data: evidence.json, X API responses, articles, linked posts, Jev docs, web copies
```

## Method and provenance

- **Evidence list:** parsed from `reports/trends.md` (the data behind the hub's Trends tab) by `bin/evidence_collect.py`.
- **X content:** fetched through the X API v2 on 2026-09-26, about 30 requests in total. This covers full text including long posts, same-author threads from the last 7 days, quoted and replied-to posts, expanded t.co links, attached media, and X Article bodies with their images. Everything is saved in `raw/`.
- **External pages:** fetched with WebFetch, which summarises pages, so quotes from web pages in the notes may be abridged. Papers were downloaded and read in full. Repos were shallow-cloned and read at these commits:
  - hindsight 2fbc25e
  - hippo-memory d4e1633
  - agent-beacon df0b21b
  - lintpal 905df34
- **Failures and gaps:**
  - The Medium page returned 403, so its full text came from the author's RSS feed.
  - The Vectorize article's second table has no caption, so its candidate count is unknown.
  - One Sakana leaderboard's scores are illegible.
  - Each note marks what is "not stated" and what is inference.
- **Rebuild:** run `bin/evidence_collect.py`, then `bin/evidence_ledger.py`. The source notes and the synthesis were written by Claude from the fetched material and are not regenerated automatically.
