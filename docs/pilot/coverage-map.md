# Pilot candidate coverage and limits

This maps all 25 Tenant A candidates,24 Tenant B candidates and18 shared probes to the recorded P01–P12 evidence. It is not a passing-journey count. The discovery stories are templates: proving their engine component with a differently worded fixture does not certify the complete story.

**Full** means the selected shared probe contract is satisfied for the frozen scope. **Partial** means relevant components passed but the entire catalog sequence or all reads were not jointly established. **Diagnostic** records an unsupported/unresolved behavior. **External** requires a human/team or deployment step beyond agent execution. **Deferred** would mean intentionally unexecuted scope; hierarchy #49, ANN/load #48, migration and forced-crash work remain outside this catalog's selected completion batch.

Evidence is indexed by milestone in [completion verification](completion-verification.md), including exact runs, source revisions, inputs, responses, worker diagnostics, snapshots, retained failures and Astra decisions. The [team walkthrough](team-walkthrough.md) gives reproduction prerequisites and commands. Read the row's remaining boundary before treating a component pass as product readiness.
